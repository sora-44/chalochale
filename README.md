# ChaloChale Travel App

ChaloChale is a responsive travel website built with HTML and Bootstrap 5. It includes destination listings, travel packages, booking, contact, and account pages.

## Pages

- `index.html` - Home page with travel carousel, services, destinations, and packages
- `destinations.html` - Featured travel destinations
- `packages.html` - Detailed travel packages
- `booking.html` - Travel booking form
- `contact.html` - Contact form
- `login.html` - User login
- `signup.html` - New account registration
- `about.html` - About ChaloChale

## Features

- Responsive Bootstrap navigation
- Destination and package cards
- Bootstrap booking modal on the home page
- Travel booking form
- Login and signup forms
- Responsive layout for desktop and mobile devices

## Run the Project

Open `index.html` directly in a browser, or run a local server from the project folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.
